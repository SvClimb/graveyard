# Кладбище проектов

Хеллоуинская страница: вставляешь ссылку на профиль GitHub или GitLab и получаешь картинку-кладбище. На надгробиях заброшенные репозитории, а из земли торчат руки зомби у проектов, которые внезапно ожили после долгой спячки.

- Надгробие: нет коммитов 6+ месяцев или репозиторий в архиве.
- Рука зомби: перерыв 6+ месяцев, потом коммит за последние 45 дней.
- Призрак висит над самым древним покойником.
- Форки не учитываются.

Картинка анимированная: молнии, туман, летучие мыши, свечи. Её можно сохранить как PNG или как 8-секундное видео.

Всё работает в браузере через публичные API GitHub и GitLab, сервер не нужен. Ссылка вида `#github-ник` сразу открывает кладбище этого пользователя.
