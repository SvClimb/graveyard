    Как мы хороним

    • Надгробие получает репозиторий без коммитов 6 месяцев и дольше, а также всё, что лежит в архиве. На камне даты рождения и последнего коммита.
    • Рука зомби торчит, если проект проспал 6+ месяцев, а потом в нём появился коммит за последние 45 дней.
    • Форки не считаются: чужих покойников не хороним.
    • Данные берутся из публичных API GitHub и GitLab прямо в браузере. Без токена GitHub даёт 60 запросов в час.
    Ничего не сохраняется на сервере: картинка рисуется у вас в браузере.
